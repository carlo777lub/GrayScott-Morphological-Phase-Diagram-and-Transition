# RECLASSIFICATION_NOTE.md

## Traceable reclassification of residual `label = 0` points

This document accompanies the script:

```text
gs_hopf_refined_band_scan_squareU01_reclass_EN.py
```

It formalizes the reclassification of residual points originally labeled as `label = 0` in the refined scan around the lower Hopf branch for the square perturbation `U0 = 0.10`, `V0 = 0.90`, with homogeneous Neumann boundary conditions.

## Motivation

During the post-processing review of the unified frontier file, residual points labeled as `label = 0` were identified. These points were not assigned to a final morphological class by the minimal frontier classifier, but their temporal metrics show significant variability.

The metric used for this audit is the temporal standard deviation of the spatial mean of `V` over the final statistical window:

```text
tstd = std_t(<V>)
```

The temporal threshold used by the classifier is:

```text
TH_TEMPORAL = 1e-3
```

For consistency with the temporal criterion used by the classifier, every residual point satisfying:

```text
label_original == 0 and tstd >= TH_TEMPORAL
```

is reclassified as:

```text
label_final = 3
```

In this version, class `3` is interpreted as:

```text
Temporally variable / contact inhibition
```

## Implemented rule

The rule added to the code is:

```python
if label_original == 0 and tstd >= TH_TEMPORAL:
    label_final = 3
```

This rule does not modify any numerical simulation fields (`F`, `K`, `meanV`, `stdV`, `tstd`, `maxV`, `area_frac`, `npeaks`). It only updates the final morphological assignment of residual points according to an explicit temporal criterion.

## Traceability

To avoid a silent correction, the code explicitly preserves the original label and the final label. CSV files generated by the updated version include the columns:

```text
label
label_original
label_final
reclassification_reason
```

The column `label` is kept as the final label for compatibility with plotting and frontier-extraction scripts. The column `label_original` preserves the initial algorithmic classification. The column `label_final` records the label after reclassification. The column `reclassification_reason` documents why the point was changed.

For points reclassified during a new simulation, the reason is recorded as:

```text
label0_reclassified_as_temporally_variable_tstd_ge_TH_TEMPORAL
```

For points reclassified during `merge` from legacy CSV files that did not yet contain traceability columns, the reason is recorded as:

```text
legacy_label0_reclassified_as_temporally_variable_tstd_ge_TH_TEMPORAL
```

## Audit file generated by `merge`

When the `merge` command is executed, the script generates an additional audit file:

```text
reclassification_audit_label0_temporal.csv
```

This file contains only the points that changed from:

```text
label_original = 0
```

to:

```text
label_final = 3
```

This makes it possible to inspect the reclassification point by point.

## Recommended command for merging legacy CSV files

If `points_block_*.csv` files already exist from before this modification, the full simulation does not need to be repeated. Run `merge` with the updated script:

```bash
python -u gs_hopf_refined_band_scan_squareU01_reclass_EN.py merge \
    --outdir out_hopf_band_cuadrada_u01_v09_neumann_ref \
    --K-clean 0.045 \
    --th-temporal 0.001 \
    --make-plots
```

The command above applies the reclassification during the merge step, preserves the original labels, and generates the audit file.

## Suggested note for a manuscript or repository

> During the post-processing audit of the refined Hopf-band scan, residual points originally labeled as `0` were inspected using the temporal variability metric `tstd = std_t(<V>)`. Residual points satisfying `tstd >= TH_TEMPORAL`, with `TH_TEMPORAL = 1e-3`, were reclassified as temporally variable (`label_final = 3`). The original label is preserved in `label_original`, and the reason for the change is recorded in `reclassification_reason`.

## Scope

This reclassification is a post-processing and nomenclature correction. It does not change the Gray--Scott simulation, the time-integration scheme, the initial condition, the Neumann boundary condition, or the computed metrics. It only makes explicit the final assignment of residual points whose temporal variability exceeds the quantitative threshold defined by the classifier.
